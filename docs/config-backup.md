# 配置备份

在「设置 → 配置备份」选择导出，输入并确认至少 8 个字符的密码，保存 `.dwconfig` 文件。导入时选择同类文件并输入原密码，完成后点击「刷新界面」。密码无法找回。

备份包含邮箱账号、IMAP 授权码、GitHub Token、iCloud App 专用密码、服务器监控设置、Token 统计来源和 SSH 服务器配置、键盘设置、代理和外观偏好。凭据从操作系统凭据库读取，导入后仍写入系统凭据库。

SSH 内容限于 Digiworld 保存的服务器别名和路径；OpenSSH 的 config、Include 文件、私钥、known_hosts 和 ssh-agent 状态需要单独迁移。迁移到新设备后应检查本地路径。插件本身需要从功能库安装；备份不授予插件权限，不改变启用状态或开机启动设置。

导入按配置键、邮箱账号 ID 合并，覆盖同名项，保留其他配置。备份不包含邮件缓存、日历事件、待办、笔记、统计历史或邮箱同步游标。插件在读写配置期间暂停，完成或失败后重新启动。缺失的凭据会列在结果中，目标设备已有的对应凭据会保留；凭据库无法访问则停止操作。

格式使用版本标识、随机 16 字节盐、随机 12 字节 nonce、PBKDF2-HMAC-SHA256（600,000 次）和 AES-256-GCM。密码错误或文件认证失败时不写入配置。导出通过临时文件原子替换目标文件；导入先校验固定目标白名单，再以数据库事务写入配置，并在文件或凭据写入失败时尝试回滚。操作系统崩溃、断电或回滚期间凭据库不可用不保证跨数据库、文件和凭据库的原子性；回滚失败会明确报错，应保留原备份。
